# NDTV News Assistant (Botpress Chatbot)

An AI chatbot built on Botpress that helps users discover and get briefed on news. It uses a knowledge base of NDTV pages plus web search to answer questions about topics, locations and timeframes.

## Live Demo
[Chat with the bot](https://cdn.botpress.cloud/webchat/v5.0/shareable.html?configUrl=https://files.bpcontent.cloud/2026/09/26/09/20260926090359-0IHT7TQR.json)

Demo page: `https://l181-blip.github.io/ndtv-chatbot`

## Features
- News discovery and news briefing playbooks
- Knowledge base of NDTV pages
- Web search for up-to-date answers
- Webchat channel, embeddable on any website

## Tech Stack
- Botpress (agent, playbooks, knowledge base, webchat)
- HTML/CSS for the hosted demo page
- GitHub Pages for hosting
